## Current limits and handoff

Only existing ZIP transformation is integrated. Browser review is tied to the pinned source/mapping bytes but is not saved/server-enforced approval. Mapping editing, clarification, corrections/rerun comparisons, structured diagnostics/history, model assistance and durable jobs are unavailable rather than simulated. Earlier test models are proposed concepts, not agreed BLU-42 contracts. See [handoff](integration-handoff.md) and [startup/walkthrough](../README.md).

Requests timeout after 120 seconds; interruption means unknown server outcome. No automatic retry/cancellation acknowledgement/reconciliation is invented. Results stay in browser memory; local links expire after 15 minutes or mode switch/reload. Preview expansion is bounded; schema/semantic validity and server artifact retention remain unestablished. Reverting this followup restores the earlier scaffold; no deployment occurred.
