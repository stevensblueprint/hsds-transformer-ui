## Interaction and failure coverage

- One picker for loose CSV/JSON+mapping or ZIP; actual request ZIP contents retain source/mapping bytes; no upload during selection, inspection, decisions or approval.
- Missing/mismatched pairs, mixed formats, malformed JSON/CSV/UTF-8, empty/oversized input, unsafe/duplicate paths, CRC/expansion/header mismatch, unsupported encryption/compression and cancellation during inspection.
- Mapping evidence/full entity paths, filters/custom backend transforms, repeated sources, preserved unknown mapping fields; reject/revise/approve and manual review questions. An answered question returns to pending; bulk review skips rejected/unresolved rows.
- Browser receipt binds current source/mapping/contract context. Editing or changing files invalidates it. Synchronous guards prevent double clicks from starting duplicate uploads.
- Source corrections require before/after/reason/scope review. Earlier source/mapping snapshots and output stay unchanged; rerun uses a new approved version. Comparison is limited to visible JSON previews and flags changed source versions/uncertain record identity rather than resolved diagnostics.
- Actual HTTP 422 versus 500 versus disconnection; three explicit attempts per version; five retained attempts/session. Stop/timeout means unknown, no cancellation acknowledgement. Late responses cannot restore cleared state or fabricate artifacts.
- Refresh clears memory-only selection, approval, history and links. Session clear confirms, Escape restores focus, unmount revokes artifacts. Artifact expiry preserves completed-response history separately from the missing link.
- Keyboard upload/review/run, skip-link focus, cancel/save focus, labels/live announcements and non-color status; axe without exclusions for intake/mapping/output, including 320px reflow. Light palette under dark preference is intentional; no designed dark theme is claimed.
- Literal HTML/formula values remain text, with no source storage, analytics, raw logs or payload URLs. Tests mock network; the live smoke script restricts the configured endpoint to localhost.

## Review findings and resolution

1. Removing staged files could retain runnable earlier inputs. Removal now clears current input/decisions/review; component/hook/browser regressions prove the old selection cannot be reapproved or uploaded.
2. Reinspection after editing could restore original pre-edit files. Saved source/mapping revisions now synchronize the staged files; tests revisit intake and confirm corrected bytes remain.
3. Version-keyed editors could lose keyboard focus after saving. A stable workspace heading takes focus when the source/mapping version changes; browser assertions cover both edit paths.

[Isolated red evidence](evidence/interactions/review-regression-red.txt) deliberately recreates the first two reviewed defects in a temporary source copy; regression tests fail there while the candidate tests pass. The working source was not modified for that sensitivity check. This is a regression-sensitivity check, not a claim that an earlier published commit contained those defects.
